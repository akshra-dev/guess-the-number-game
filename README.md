# 🎮 Guess the Number Game

A Python-based interactive guessing game with multiple difficulty levels, scoring system, and time-based challenges.

## 🚀 Features

* 🎯 Multiple difficulty levels (Easy, Medium, Hard)
* ⏱️ Time-limited gameplay
* 🏆 Score calculation with multipliers
* 📊 Game statistics (games played, win rate)
* 💡 Hint system to guide the player
* 🔁 Replay and difficulty change options

## 🛠️ Technologies Used

* Python
* Built-in modules:
  * "random"
  * "time"

## 🎮 How to Play

1. Choose a difficulty level:
   * Easy (1–50)
   * Medium (1–100)
   * Hard (1–200)

2. The game selects a random number within the range.

3. You have limited attempts and time to guess the number.

4. After each guess:
   * You get hints (closer/farther)
   * You are told if your guess is too high or too low

5. Win the game by guessing correctly before attempts or time run out.

## 🏆 Scoring System

* Score is based on:

  * Number of attempts used
  * Difficulty level (multiplier)
  * Time taken (bonus points)

## 📊 Game Stats

* Tracks:
  * Total games played
  * Games won
  * Win rate

## ▶️ How to Run

1. Make sure Python is installed
2. Download the file:
   guess_the_number_game.py
3. Run the program:
   python guess_the_number_game.py
